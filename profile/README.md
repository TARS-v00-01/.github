# TARS — xWalk robotics

Raspberry Pi robotics, desktop and Android controls, model training, and Yocto image tooling.

### Join the organization

**[Request membership](https://github.com/TARS-v00-01/.github/issues/new?template=membership-request.yml)**

Submit a request, wait for an organization owner's approval, and accept the GitHub invitation.
Approved members receive Read access to the organization's private repositories. Membership does not grant
permission to push into those repositories: propose fixes through private forks and pull requests.

[How requests and contributions work](https://github.com/TARS-v00-01/.github/blob/master/CONTRIBUTING.md)

### Projects

- [Raspberry Pi integration](https://github.com/TARS-v00-01/xWalkPiCarAI)
- [Desktop, Android, model and image tooling integration](https://github.com/TARS-v00-01/xWalkPiCarApp)

Public integration repositories describe the projects and pin their private modules. Maintainers merge accepted
changes through Gerrit and CI before publishing them to GitHub.
